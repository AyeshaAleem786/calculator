# C Calculator

A menu-driven command-line calculator written in C. It supports basic and
advanced operations, handles invalid input safely, and keeps a history of
recent calculations.

## Features

- Addition, subtraction, multiplication, division and modulus
- Power and square root (using `math.h`)
- Factorial for numbers from 0 to 20
- Input validation: no crash on wrong input, division by zero or negative square root
- History of the last 10 calculations
  
## Concepts Used

Functions, pointers, arrays, switch-case, loops, string handling and
input validation.
